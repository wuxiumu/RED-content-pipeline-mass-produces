# 02 · 判断智能体 Judge

> 做决策。把 01 的市场数据与词族表合并,排出"今天生产哪个词、走什么角度"的队列。
> wordcard 轨支持无样本冷启动(直接按词族表排产);video/resource 轨依赖爆款样本做选题。

## 1. 定位

- 输入:`data/collected.json` + `assets/wordlists/word_families.yaml` + `data/feedback.json`
- 输出:`data/judged.json` —— 三轨选题队列,带优先级
- 不做:不抓数据、不写台词、不生图

## 2. wordcard 轨:词族排产模型(主力,规则为主)

每个候选词打分 0-100,权重设计体现启蒙赛道"收藏 + 求资源"逻辑:

| 维度 | 权重 | 数据来源 |
|---|---|---|
| 词族常见度/认知顺序 | 25 | 词族表 `priority`(水果/动物/食物靠前) |
| 收藏率信号 | 30 | 样本收藏/点赞(T+7 回流;冷启动用点赞代理) |
| 历史反馈 | 20 | feedback:该词/同族词的收藏率、扣 1 数 |
| 竞争留白 | 15 | 同主题高赞样本越少越加分(反向) |
| 视觉可画性 | 10 | 规则表:具体实物高分,抽象词(礼貌/情绪)低分 |

**冷启动(无样本、无反馈)**:常见度 + 视觉可画性归一化后直接排序,水果族 → 动物族 → 食物族顺序日产 1 词。
**运行后**:feedback 里收藏率 >0.8 或扣 1 评论占比高的词族整体加权,连续扩产该族;低表现族降频。

选题字段不需要 LLM(一个词就是一个选题),angle 固定为"4 句认知公式",但 03 会让 LLM 生成 5 个**封面标题**候选再自评选 1。

## 3. video / resource 轨:样本驱动(LLM)

对每轨 top 5 关键词:

### 3.1 爆款范式提炼(LLM)
- **video**:标题结构("2岁娃看了主动开口…""省妈神器…")、标签簇、封面共性(大字+萌物)、前 3 秒钩子
- **resource**:钩子类型(50000 秒/可投屏/可打印/免费领)、封面(资源墙截图+大字数字)、评论区导流话术范式

### 3.2 选题生成(LLM,每词 4 候选)
- video 选题必须复用 wordcard 已有蜡笔形象(一鱼多吃,不另起美术)
- resource 选题必须挂**合规钩子**:只说"原创/自制/公版整理",禁止"50000 集动画"式盗版表述与知名 IP 名
- 字段:`title_hint / angle / tags_hint / target_audience / cross_sell_hint`

## 4. 通用选题评分(纯 Python)

- 标题含数字 +15、含年龄锚点(2岁/3岁/幼儿园前)+10、含省妈/开口/跟读等结果词 +10
- 标题 12-20 字 +5;标签 4-6 个 +5
- resource 轨带合规 CTA +15;出现微信/外链/盗版词 -100(直接淘汰)
- video 轨能复用现有词族形象 +10

## 6. 执行流程

```
1. 读 collected.json(可无 samples)+ 词族表 + feedback.json
2. wordcard:词族表展平为候选 → 规则打分 → 排 queue(默认取当天要产的 N 个词)
3. video/resource:样本按词聚合 → 规则评分 → top 5 词 LLM 提炼范式 + 生成选题 → 评分排序
4. 合规过滤:盗版/IP/外链表述直接淘汰并打印日志
5. 输出 judged.json
```

LLM 调用走 GLM-5.3-Flash,失败降级为纯规则结果,不阻塞排产。

## 7. 与 03 的交接

- 03 按 `priority` 消费 wordcard 队列,每个词跑完台词→生图→9 页卡→组装,写回状态
- 不可执行词(如生图连续失败)标 `status: skipped` + 原因,02 下轮降权
- `reuse_word_id` 是 video 轨复用 wordcard 美术资产的关联键
- feedback 回流后:高收藏词族扩产、高扣 1 词族加排 resource 联动帖
